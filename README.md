# Wither Skull Drop Rate — Issue Tracker

Report bugs, request features, and report compatibility problems with Wither Skull Drop Rate.

## Report a bug

Open the Issues tab, click New issue, and include:

- Minecraft version
- Mod version
- Fabric Loader and Fabric API versions
- What happened and what you expected
- Steps to reproduce the problem
- Relevant logs, crash reports, or screenshots
- Other installed mods, if relevant

Search existing issues before submitting a report. Remove personal information from logs before uploading them.

## Request a feature

Create an issue describing your idea and how it would improve the mod.

## About the mod

Wither Skull Drop Rate lets you configure the chance of Wither Skeleton skull drops from 0% to 100%. Edit config/witherskullrate.json, then run /reload or restart the world or server.

This repository is for issue tracking and feature requests. It does not contain the mod’s source code.
